# Version 2 figures (V01 to V17)

Drawn by `build-figures.mjs` in this folder (copied from the Version 1 generator in `midsem/docs/figures`, paths pointed at `finalsem/`). SVG sources are in `svg/`, PNGs are in this folder, and `_contact-sheet.png` shows all of them. Rebuild with `node finalsem/docs/figures/build-figures.mjs` (Playwright's headless Chromium from `finalsem/project/node_modules`; no window, no extension, no model).

Checks run on every build: all text at least 22 px, box titles 24 to 26 px bold, no text wider than its box, no two text items overlapping, all text inside the canvas, every figure at most 1000 px tall and 1600 px wide.

## Where each number comes from

- **NVIDIA writing speed, 34 to 53 tokens a second:** the decode figure of each run's last request (`stats.decodeTps` is set from `engine.lastStats` in `service-worker.js`). Clean runs only: 47, 53 and 34 in `v2-local-nvidia-cold-first-attempt.md`; 40 and 42 in `v2-local-nvidia-offline.md`.
- **Intel writing speed, 4 and 5 tokens a second:** `v2-local-intel.md` (SmolLM2 360M, the model the extension picks on integrated graphics).
- **Intel with Llama 3.2 1B, about 2 tokens a second:** only in the DEVLOG speed test (21 Oct). No saved run file. Drawn as a dashed bar in V08 and labelled that way.
- **About 63 tokens a second writing and about 600 a second reading the prompt:** only in the DEVLOG speed test (21 Oct). No saved run file. Shown in V15 with that label. The DEVLOG row does not say what text was used.
- **Times:** from the timeline stamps of the clean runs. Segment times are the differences between stamps.
- **Model sizes:** about 695 MB (Llama 3.2 1B, popup text in the clean run) and about 204 MB (SmolLM2 360M, popup text in the Intel run). Graphics memory 879 MB and 376 MB are WebLLM's `vram_required_MB` values in `config.js`.
- **36,752 characters (Lighthouse):** `midsem/docs/test-runs/live-measurements.md`, row L04.

- `v2-local-nvidia.md` (207 s, 17 s, 101.6 s), `v2-local-nvidia-cold-second-attempt-with-load.md` (same numbers) and `v2-local-nvidia-offline-first-attempt-with-load.md` (13.4 s, 32.2 s): done while other programs were using the processor. Not charted. `v2-local-nvidia.json` is the file of the disturbed run, so it is not used either.
- The clean cold NVIDIA run has no JSON file. Its numbers come from its Markdown tables and timelines.
