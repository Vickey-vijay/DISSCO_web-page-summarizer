# AI-Powered Web Page Summarizer (Chrome Extension)

A Chrome extension that summarizes the page you are reading in one click.

- **V1 (midsem):** sends the page text to a cloud LLM API (free-tier key entered once in the extension's Options page).
- **V2 (final sem):** runs a small model inside the browser, so no API key is needed and the page text stays on your machine.
